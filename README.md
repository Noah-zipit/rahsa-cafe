# Rahsa Cafe

A cozy 3D low-poly cafe management game. Cook, serve, and grow your little cafe on a warm city square.

**Live:** https://rahsa-cafe.vercel.app

## About

- Fixed-diorama 3D world built with Three.js — warm, cozy lighting, full-bleed portrait view
- Two cooks share one progress bar; keep the orders flowing
- City-square exterior to explore between rushes

## Assets

In-game art uses real artist-made packs (CC0 / permissive, credited): Kenney and Quaternius, plus procedural chibi NPCs. AI-generated art is used for UI/dish icons only.

## Run locally

```bash
npm install
npm run dev
```
